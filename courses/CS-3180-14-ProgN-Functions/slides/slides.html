Implicit ProgN

  • Many functions in Lisp give you an IMPLICIT progn
  • defun is one of these functions
  • if is NOT
  • Let's see both of those
  • main is generally impure, let's write one

Main

  • defun will still create global function
  • We'll just call main
(defun square (value)
    (format t "squaring value...~%")
    (* value value))

(defun main () 
    (format t "Hello world~%")
    (format t "4 squared is ~S~%" (square 4)))


(main)

When

  • Kind of like an if, but re-framed
  • When 1st argument is non-nil, evaluate the 2nd
  • Evaluate to nil otherwise
  • Implicit ProgN
(defun foo (x)
    (when (> x 0)
        (print "Positive")
        (* x 2)))

(format t "Value was: ~S~%" (foo 5))
(format t "Value was: ~S~%" (foo -5))

Unless

  • When 1st argument IS nil, evaluate the 2nd
  • Opposite of when
  • Implicit ProgN
  • Equivalent to (when (not test) body)
(defun my-sqrt (value)
    (unless (< value 0)
        (print "square rooting number...~%")
        (sqrt value)))

(format t "Value was: ~S~%" (my-sqrt 5))
(format t "Value was: ~S~%" (my-sqrt -5))

Cond

  • If-else-if-else block
  • This will always work
  • May not always want the jackhammer for the nail
  • Lazily evaluates all of its test forms
  • Each FULL FORM is one argument to cond, with a progn
  • Let's see this

Cond

  • Catch-all becomes t
  • Each arg is of the form (test body)
(defun get-letter-grade (score)
    (cond 
        ((>= score 90) "A")
        ((>= score 80) "B")
        ((>= score 70) "C")
        (t "F")))

(defun main ()
    (format t "Your letter grade was ~S~%" 
        (get-letter-grade 94))
    (format t "Your letter grade was ~S~%" 
        (get-letter-grade 35)))

(main)

Cond ProgN

  • ProgN here can complicate things
  • Formatting gets difficult

(defun get-letter-grade (score)

Let

  • Scoped Variables*, finally
  • Constant Name Bindings
  • Body of the let function -> becomes the scope of the variable
  • Implicit progn
  • Returns the last value as a result
  • Start with some small examples

Let

  • Pay close attention to the ()s
  • One of these ()s feels redundant

(defun get-letter-grade (score)
    (cond 
        ((>= score 90) (format t "Excellent~%")   "A")
        ((>= score 80) (format t "Good Job~%")    "B")
        ((>= score 70) (format t "...~%")         "C")
        (t             (format t ":(~%")          "F")))

(defun main ()
    (let ((grade (get-letter-grade 97)))
        (format t "Hi Bob~%")
        (format t "You got the following grade: ~S~%" grade)))

(main)

SetQ

  • Evil imperative keyword
  • Update a local binding
  • Combine with when for a gaurd clause
(defun abs-square (value)
    (when (< value 0)
        (setq value (abs value)))
    (* value value))

(format t "Value was: ~S~%" (abs-square -5))
(format t "Value was: ~S~%" (abs-square -3))
