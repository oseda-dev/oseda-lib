'Dunder' Methods

  • Double Underscore = 'Dunder'
  • Python treats these as special methods
  • Usually called implicitly
  • There is a lot of these you can override
  • E.g. __add__ gets called when you use + on two classes

__examples__

class Number:
    # gets called when instantiated
    def __init__(self, value):
        self.value = value

    # gets called when + is used
    def __add__(self, o):
        return Number(self.value + o.value)

    # string representation
    def __repr__(self):
        return str(self.value)


n1 = Number(2)
n2 = Number(3)

result = n1 + n2
print(result)

class Person:
    def quack(self):
        print("*Human like imitation of a quack*")

class Dog:
    def bark(self):
        print("Woof!")


# will check if this method exists at runtime, then call it

    animal.quack()

Encapsulation

  • Abstraction is about hiding data
  • Only expose the necessary parts of system
  • We don't want the users to have unfettered access to our data
  • That's part of why we made a class to begin with
  • Control the state
  • Encode rules into your type system
  • Java: private/public/protected keywords
public class Account {

    // prevent people from accessing via account.balance
    private int balance = 1000;


    // allow anyone to create an account
    public Account(int startingBalance){
        this.balance = startingBalance;
    }

    // public access function
    // allow the world to see
    public int getBalance(){
        return this.balance;
    }

    // private mutator function
    // prevent world from editing
    private void setBalance(int newBalance) {
        if(this.balance - newBalance < 0){
            throw new RuntimeException();
        }

        this.balance = newBalance;
    }

    // enforce the caller to use a method with 
    // other parameters/guards on it
    public void processTransaction(Transaction t) {
        System.out.println("Processing transaction...");
        setBalance(t.amount);
    }
    
}
  • Keywords allow us to restrict the access
  • Accessing a private member: Code does not compile
class Main {
    public static void main(String[] args) {

        Account a = new Account(500);
        // allowed to access public methods
        a.processTransaction(new Transaction(100));


        // does not compile
        a.balance = 400;
    }
}

Python Encapsulation

  • Python does NOT have any similar protection
  • Enforced via convention:
  • Use an underscore for private members
  • You can still change them

No Safe Guards

class Account:

    def __init__(self, startingBalance):
        # single underscore for fields
        self._balance = startingBalance

    def get_balance(self):
        return self._balance

    # two underscores for method
    def __set_balance(self, newBalance):
        if self._balance - newBalance < 0:
            raise RuntimeError()
        self._balance = newBalance

    def process_transaction(self, amount):
        print("Processing transaction...")
        self.__set_balance(amount)


a = Account(500)
a.process_transaction(100)

a._balance = -200
print(a._balance)
