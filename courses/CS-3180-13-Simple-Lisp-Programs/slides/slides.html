Defparameter

  • Defines a global variables
  • "Earmuff" notation?
  • Can fill this with Symbolic Expressions
  • Only use this with globals
(defparameter *variable-name* value)

(defparameter *age* 30)

(defparameter *months* (+ 3 5))

(format t "I am ~S years and ~S months old~%" *age* *months*)

Word of Caution

  • Haven't we just written procedural code?
  • Antithetical to Lisp
  • Named intentionally -> "Define Parameter"
  • Think of it as a parameter instead of a side-effect
  • "Pollutes the global namespace"
(defparameter *age* 30)
(format t "I age ~S years old~%" *age*)
    
(setf *age* (* 5 7))
(format t "I am now ~S years old~%" *age*)

Updating "Variables"

  • Setf to update a variable
  • Hesitate to use this on labs
  • Mutating global state
  • Necessary evil for "bootstrapping" your Lisp knowledge
(defparameter *age* 30)
(format t "I age ~S years old~%" *age*)

(setf *age* (* 5 6))
(format t "I am now ~S years old~%")

User Input

  • Lisp gives you a "simple" function
  • read-line to read input as a string
  • Code like this often leads to race conditions
  • Symptomatic of a bad paradigm
  • finish-output to block until all buffers are flushed
(format t "What is your name?~%")
(finish-output)
(defparameter *name* (read-line))

Input as Data

  • You can also read input as data
  • Executor assumes its just Lisp code
  • Similar a quote in some ways
  • Will also coerce types for you
(format t "Enter something Lisp-like: ")
(finish-output)
(defparameter *code* (read))

(format t "You entered: ~S~%" *code*)
(format t "The type was: ~S~%" (type-of *code*))

Functions

  • Define function via defun
  • Parameters are just a list
  • Scoped to the body -> Important
  • Evaluate to their LAST expression evaluated
  • Let's see how this works
(defun function-name (parameter-list)
    body-expression)

Functions

  • Doc String as a parameter
(defun square (x)
  (* x x))

(format t "~S~%" (square 5))

; / will just return a "ratio" if both values are ints
(defun do-some-math (value divisor)
    (/ (square value) (float divisor)))

(format t "~S~%" (do-some-math 5 2))

(defun cube (value)
    "Returns the cube of the number"
    (* value value value))

Summary

  • defparameter and setf for globals
  • Pollute the namespace
  • if function for simple conditionals
  • defun for functions
